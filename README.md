# 掼蛋 Guandan — 多人扑克游戏

掼蛋（Guandan）多人扑克牌游戏的 Web 应用，支持本地双人、多人对局，基于 React + Vite 构建。

A web app for the popular Chinese card game **Guandan (掼蛋)**, with local and multiplayer modes. Built with React + Vite.

## 运行 / Run

```bash
npm install
npm run dev
```

浏览器访问 / Open http://localhost:8080

## 脚本 / Scripts

- `npm run dev` — 开发服务器 / dev server (port 8080)
- `npm run build` — 构建 / build
- `npm test` — 测试 / tests
- `npm run typecheck` — 类型检查 / type check
